# Security policy

## Supported versions

Only the latest commit on `main` is supported. If you deployed your own copy, update it from this repository to get fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's [Report a vulnerability](https://github.com/ianmenethil/cf-templates-shortlinks/security/advisories/new) form, with the steps to reproduce it and what an attacker could do.

Once a fix is ready, it is released on `main` and the advisory is published with credit to you, unless you prefer not to be named.

A problem in a library this project uses belongs with that library's maintainers. A problem in how one deployment is set up, such as a Cloudflare Access policy that lets the wrong people in, belongs with whoever runs that deployment.
